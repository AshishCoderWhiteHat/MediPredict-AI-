# MediPredict AI - Data Directory

## Structure:
- `raw/`: Stores the untouched clinical dataset (`diabetes.csv`) with verified SHA-256 fingerprint.
- `processed/`: Stores cached preprocessing records, validation reports, or transformed training slices.

## Provenance:
- **Origin:** Pima Indians Diabetes Database (National Institute of Diabetes and Digestive and Kidney Diseases).
- **Rows:** 768 observations.
- **Columns:** 8 features + 1 binary target (`Outcome`).
- **Cryptographic Hash (SHA-256):** `698c203a14aa31941d2251175330c9199f3ccdb31597abbba2a3e35416257a72`
